Odds Tracker

This project tracks what would happen if you placed a hypothetical $100 bet on every team in every regular-season game. About an hour before each game, it records the moneyline odds from Kalshi for both sides. After the game, it records the final result.

It covers the NBA, NHL, MLB, NFL, and college football. No real money is involved, and no Kalshi account is needed. The project only reads public prices.

With a full season of data, it can answer questions like:

How much would $100 on a single team every game have made or lost over the season?
What about $100 against a team, for example betting against the worst teams or backing the upset against the best?
How often does the home team win, and how often do underdogs win?
Which leagues have the most efficient odds, and which have the least?

Data is collected automatically with GitHub Actions and saved to a CSV file in this repo.
